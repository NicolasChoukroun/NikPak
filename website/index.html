Why NikPak

One small program, designed around four ideas: compress better, go faster, protect with modern cryptography, run unchanged everywhere.

Quantum-resistant

Only 256-bit symmetric cryptography. There is no RSA, elliptic-curve or Diffie-Hellman code for a quantum computer to break.

Media-aware

WAV, AIFF, ProTracker MOD and BMP files are recognised by their content, not their name. Each one is tried with several lossless filters and the smallest result wins.

Office and PDF recompression

The Deflate streams inside docx, xlsx, pptx, odt, epub, pdf, zip and gz files are unpacked, compressed far better and rebuilt bit for bit when you extract.

Smallest at the maximum level

At -m5 NikPak picks LZMA2 or PPMd for each block and sorts files by type. It made the smallest archive of all four tools on every test set.

Fast when you need it

At the fast level -m2, 190 MB of source code is archived in 1.7 s on one core, 56 times faster than 7-Zip's default level.

Encryption done right

Argon2id with 64 MiB of memory and XChaCha20-Poly1305 authenticated encryption. File names, sizes and dates are always hidden, and tampering is always detected.

Archive size at the maximum level

Percentage of the original size: lower is better. One CPU core, every archive extracted again and compared byte for byte.

One window. Drop, and it's done.

Drop files or folders on the NikPak window, or click the circle to choose them. They are compressed with the best compression into one archive. The ring shows the progress and turns green when the archive is ready.

  • Best compression (-m5) by default
  • Remembers your destination folder
  • Cancel at any time with Esc; nothing half-written is left behind
  • An existing archive is never overwritten

unNik: the free archive browser

Double-click a .nik file and unNik opens it. Browse the folders, search the whole archive, view text and binary files, extract a selection, delete files or test the archive. unNik is freeware, for individuals and companies alike.

  • Folder tree, breadcrumbs, search with Ctrl+F
  • Built-in viewer for text (with search) and binary files
  • Extract all or a selection, keep both or replace
  • Switch between NikPak and unNik with one button

A command line RAR users already know

a, x, e, l, t, @listfiles, -p, -o+, -y: front-ends such as Total Commander can drive nikpak.exe like rar.exe. Clear exit codes make it a solid choice for scripts and backups.
