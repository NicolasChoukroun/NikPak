Benchmarks

NikPak, RAR 7.00, 7-Zip 23.01 and Info-ZIP 3.0, run one after another on the same machine and the same files.

On this pageMethodArchive size at the maximum levelMaximum level: archive size in bytesFast levels: size and creation timeGeneral data in detailReading the results honestly

Method

  • Linux x86-64 virtual machine (Intel Xeon, 2.8 GHz). Every tool pinned to one CPU core and run single-threaded.
  • Maximum levels: nikpak -m5, RAR -m5 -s, 7-Zip -mx9, ZIP -9. Fast levels: nikpak -m2, RAR -m3 -s, 7-Zip -mx5, ZIP -6.
  • All 92 archives were extracted again and compared with the originals: all were identical.
  • Public test material: scikit-image photographs, the libxmp MOD collection, LibreOffice gallery sounds, music rendered with TiMidity++, Project Gutenberg books, office files, the Python standard library and C headers.

Reading the results honestly

  • NikPak -m5 is the smallest on every set: 2.4 to 31.7 % smaller than 7-Zip -mx9, 10.8 to 38.4 % smaller than RAR 7 -m5 and 19.9 to 60.4 % smaller than ZIP -9.
  • Recorded audio: on the 24-bit music 7-Zip saves 12 % and NikPak 37 %, because the NAC codec predicts what general compressors can only match.
  • Office files, 31.7 % smaller than 7-Zip, thanks to Deflate recompression. The price at -m5 is time: 81 s against 26 s.
  • Text, 15.9 % smaller in half the time: PPMd wins on prose. It decodes as slowly as it encodes, so extraction takes 2.7 s instead of 0.2 s.
  • Fast level -m2: 1.7 s for the general set, against 93.7 s for 7-Zip -mx5, 48.2 s for RAR and 7.3 s for ZIP. It is not the smallest on text and source code, which is why -m5 is the default.
  • Extraction: 0.9 s (-m2) or 5.6 s (-m5) for the general set, against 6.0 s for 7-Zip, 6.7 s for RAR and 6.9 s for ZIP.
  • The cost: -m5 trades time for size. The figures above pin every tool to one core; since 1.13 a -m5 archive spreads its blocks across the cores in real use. A faster maximum level stays on the roadmap.

Figures from the NikPak technical guide (section 11.7, NikPak 1.2.0). Measure on your own files: nikpak mt shows what each media filter achieves without writing anything.
